### Requirement: Сводка по категориям
Система SHALL предоставлять команду `summary` для вывода агрегированных сумм расходов по каждой категории.

#### Scenario: Сводка без фильтров
- **WHEN** пользователь выполняет `summary`
- **THEN** система выводит таблицу: категория, сумма, количество записей — для всех категорий с расходами, плюс итоговую строку

#### Scenario: Сводка с фильтром по датам
- **WHEN** пользователь выполняет `summary --from 2026-07-01 --to 2026-07-31`
- **THEN** система агрегирует только записи в указанном диапазоне

#### Scenario: Сводка с фильтром по категории
- **WHEN** пользователь выполняет `summary --category еда`
- **THEN** система выводит сводку только по категории «еда»

#### Scenario: Нет данных для сводки
- **WHEN** пользователь выполняет `summary` при отсутствии записей (или в пустом диапазоне)
- **THEN** система выводит сообщение «Расходов нет»

### Requirement: Категории без расходов не отображаются
В выводе `summary` SHALL отображаться только категории, по которым есть хотя бы одна запись в выбранном диапазоне.

#### Scenario: Частичные данные
- **WHEN** в хранилище есть записи только по категориям «еда» и «транспорт»
- **THEN** сводка показывает только строки «еда» и «транспорт», без пустых строк для остальных категорий
