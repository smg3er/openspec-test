## ADDED Requirements

### Requirement: Добавление расхода
Система SHALL предоставлять команду `add` для записи нового расхода с обязательными полями: сумма (положительное число), категория (из фиксированного списка), дата (YYYY-MM-DD). Необязательное поле: текстовый комментарий.

#### Scenario: Успешное добавление расхода
- **WHEN** пользователь выполняет `add --amount 500 --category еда --date 2026-07-29 --note "бизнес-ланч"`
- **THEN** система сохраняет запись в JSON-файл и выводит подтверждение с ID записи

#### Scenario: Добавление без комментария
- **WHEN** пользователь выполняет `add --amount 200 --category транспорт --date 2026-07-29`
- **THEN** система сохраняет запись с пустым комментарием и выводит подтверждение

#### Scenario: Неверная категория
- **WHEN** пользователь указывает категорию не из списка (еда, транспорт, жильё, развлечения, прочее)
- **THEN** система выводит ошибку со списком допустимых категорий и не сохраняет запись

#### Scenario: Неверный формат суммы
- **WHEN** пользователь указывает неположительную или нечисловую сумму
- **THEN** система выводит ошибку и не сохраняет запись

#### Scenario: Неверный формат даты
- **WHEN** пользователь указывает дату не в формате YYYY-MM-DD или несуществующую дату
- **THEN** система выводит ошибку и не сохраняет запись

### Requirement: Присвоение уникального идентификатора
Каждая запись SHALL получать уникальный идентификатор (UUID4) при создании.

#### Scenario: Генерация ID
- **WHEN** пользователь добавляет новый расход
- **THEN** система присваивает записи UUID4 в поле `id`
