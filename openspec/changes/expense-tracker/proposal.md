## Why

Команда записывает расходы (обеды, такси, прочее) в общую Excel-таблицу, которая со временем стала нечитаемой: версии теряются, итоги не собрать, структура у каждого своя. Нужен простой инструмент для записи и просмотра расходов без лишней сложности.

## What Changes

- Новая CLI-утилита на Python с подкомандами `add`, `list`, `summary`
- Фиксированный набор категорий: еда, транспорт, жильё, развлечения, прочее
- Хранение данных в локальном JSON-файле
- Фильтрация записей по диапазону дат (от/до) и по категории
- Сводка расходов по категориям за период

## Capabilities

### New Capabilities

- `expense-recording`: Добавление записей о расходах с суммой, категорией, датой и комментарием
- `expense-querying`: Просмотр списка расходов с фильтрацией по датам
- `expense-reporting`: Агрегированная сводка расходов по категориям

### Modified Capabilities

(нет — проект новый, существующих спецификаций нет)

## Impact

- Новый Python-проект в корне репозитория
- Зависимости: стандартная библиотека + возможно `click` или `argparse` для CLI
- Данные хранятся в `expenses.json` в рабочей директории
- Нет внешних сервисов, БД, или сетевого взаимодействия
