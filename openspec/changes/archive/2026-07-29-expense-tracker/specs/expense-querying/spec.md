## ADDED Requirements

### Requirement: Просмотр списка расходов
Система SHALL предоставлять команду `list` для вывода всех сохранённых расходов в табличном формате: дата, категория, сумма, комментарий.

#### Scenario: Список без фильтров
- **WHEN** пользователь выполняет `list`
- **THEN** система выводит все записи, отсортированные по дате (новые сверху)

#### Scenario: Пустое хранилище
- **WHEN** пользователь выполняет `list` при отсутствии записей
- **THEN** система выводит сообщение «Расходов нет»

### Requirement: Фильтрация по датам
Команда `list` SHALL поддерживать необязательные флаги `--from` и `--to` для фильтрации по диапазону дат (включительно).

#### Scenario: Фильтр по начальной дате
- **WHEN** пользователь выполняет `list --from 2026-07-01`
- **THEN** система выводит только записи с датой >= 2026-07-01

#### Scenario: Фильтр по конечной дате
- **WHEN** пользователь выполняет `list --to 2026-07-15`
- **THEN** система выводит только записи с датой <= 2026-07-15

#### Scenario: Фильтр по диапазону
- **WHEN** пользователь выполняет `list --from 2026-07-01 --to 2026-07-15`
- **THEN** система выводит только записи с датой в диапазоне [2026-07-01, 2026-07-15] включительно

#### Scenario: Нет записей в диапазоне
- **WHEN** пользователь указывает диапазон, в котором нет записей
- **THEN** система выводит сообщение «Расходов нет»

### Requirement: Фильтрация по категории
Команда `list` SHALL поддерживать необязательный флаг `--category` для вывода только расходов указанной категории.

#### Scenario: Фильтр по категории
- **WHEN** пользователь выполняет `list --category еда`
- **THEN** система выводит только записи с категорией «еда»

#### Scenario: Комбинация фильтров
- **WHEN** пользователь выполняет `list --category транспорт --from 2026-07-01 --to 2026-07-31`
- **THEN** система выводит только записи категории «транспорт» в указанном диапазоне дат

#### Scenario: Неверная категория в фильтре
- **WHEN** пользователь указывает в `--category` значение не из списка допустимых
- **THEN** система выводит ошибку со списком допустимых категорий
